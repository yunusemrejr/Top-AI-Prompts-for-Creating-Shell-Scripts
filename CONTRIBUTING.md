# Contributing to Top AI Prompts for Creating Shell Scripts

Thank you for helping make Linux automation with AI better!

## How to Contribute

1. **Improve Existing Content**
   - Enhance a script with new features (more options, better logging, JSON output, etc.)
   - Expand a guide with more examples or clearer explanations.

2. **Add New Content**
   - New prompt templates in `/prompts/`
   - New example scripts in `/examples/` (networking, cloud, databases, monitoring stacks)
   - New guides in `/docs/` (e.g., "Prompting for Cloud CLI wrappers", "Zsh vs Bash")

3. **Quality Standards**
   - All scripts must follow the 16 best practices.
   - All prompts must include the mandatory requirements section.
   - Add comments that explain *why*.

4. **Pull Request Process**
   - Fork → Create branch → Make changes → Test scripts → Open PR.
   - Reference related issues.

## Discoverability Tips
- Use keywords in PR titles/descriptions: AI prompt, LLM bash, shell script generation, Linux automation.
- Add topics to the repo if you have permissions: ai, prompts, bash, llm, linux, automation.

We welcome contributions from sysadmins, DevOps engineers, and AI enthusiasts!
