# Prompt: Security Hardening & Audit Script

You are a senior security engineer specializing in Linux hardening.

Generate a script that:
- Audits current SSH, firewall, kernel security settings
- Applies recommended hardening (with backups of originals)
- Checks for common misconfigurations
- Outputs a security score or recommendations

Include all best practices: strict mode, error handling, dry-run, logging, help function, comments.

Output only the complete script.
